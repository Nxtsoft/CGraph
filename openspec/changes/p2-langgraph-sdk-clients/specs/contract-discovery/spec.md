## ADDED Requirements

### Requirement: LangGraph SDK client calls become CONSUMES edges
A call `<receiver>.<group>.<method>(...)` SHALL be a client call when the receiver provably is a `Client` of `@langchain/langgraph-sdk`: a `new Client(...)` (or `new ns.Client(...)` through a namespace import) whose `Client` the file imports from `@langchain/langgraph-sdk` or `@langchain/langgraph-sdk/client`, read directly, through a block-scoped local set once, through a module constant no parameter shadows, through a class field `this.x` set once, or through a call to a module function of the same file whose every return is one; or the return value of a call to an imported function whose own file defines it at module level with every return such a `new Client(...)`. Such a call SHALL add a `CONSUMES` edge from the calling function to `endpoint:<METHOD> <path>` with the verb and path that SDK method sends in `@langchain/langgraph-sdk` 1.11.1 (`client.runs.stream(threadId, ...)` is `POST /threads/{}/runs/stream`, `client.threads.create()` is `POST /threads`, every interpolated id `{}`), counted like any client call. Where the SDK picks the path from an argument, the call SHALL follow the SDK's own test: a literal `null` or `undefined` thread id sends `runs.stream`, `runs.wait` and `runs.joinStream` to their stateless paths (`/runs/stream`, `/runs/wait`, `/runs/{}/stream`) and a literal `null` sends `runs.create` to `/runs`, while any other argument is a thread id; `threads.getState` with no checkpoint (or a literal `null`/`undefined`) GETs `/threads/{}/state`, with a string literal GETs `/threads/{}/state/{}` and with an object literal POSTs `/threads/{}/state/checkpoint`; `assistants.getSubgraphs` with an options object literal naming `namespace` GETs `/assistants/{}/subgraphs/{}`. A `runs.create(undefined, ...)`, a checkpoint or options argument the file cannot read, a method the SDK does not send over REST (`threads.stream`, which speaks the v2 protocol through a transport), and any receiver not proven to be an SDK client (a parameter typed `Client`, a local reassigned after its declaration, a parameter shadowing a module client, another package's `Client`, a function the project does not define) SHALL add no edge and no count. These calls SHALL NOT also be read as `<receiver>.<verb>` client calls.

#### Scenario: A factory in another file makes the client
- **GIVEN** `lib/langgraph-client.ts` importing `Client` from `@langchain/langgraph-sdk` and exporting `function createLangGraphClient(accessToken, service = 'luna') { ...; return new Client({ apiUrl, defaultHeaders }) }`, and `send` in another file doing `const client = createLangGraphClient(token, 'ic')`, `client.threads.create()`, `client.runs.stream(thread.thread_id, 'luna', {...})` and `client.runs.wait(null, 'recap', {})`
- **THEN** `send` consumes `endpoint:POST /threads`, `endpoint:POST /threads/{}/runs/stream` and `endpoint:POST /runs/wait`, and three calls are counted, none unresolved

#### Scenario: A client made in the file
- **GIVEN** `const shared = new Client(...)` at module level, `function makeClient(apiUrl) { return new Client({ apiUrl }) }`, a class field `private client = new Client()`, and `import * as lg from '@langchain/langgraph-sdk/client'`
- **THEN** `makeClient(...).assistants.search(...)` (through a local) is `POST /assistants/search`, `shared.store.putItem(...)` is `PUT /store/items`, `new lg.Client().runs.joinStream(null, rid)` is `GET /runs/{}/stream`, and `this.client.runs.cancel(t, 'r')` is `POST /threads/{}/runs/{}/cancel`

#### Scenario: The path follows the arguments the SDK reads
- **GIVEN** `client.threads.getState(id)`, `client.threads.getState(id, { checkpoint_id: 'c' })`, `client.threads.getState(id, cp)` and `client.runs.create(undefined, 'luna')` on a factory-made client
- **THEN** the first is `GET /threads/{}/state`, the second `POST /threads/{}/state/checkpoint`, and the last two record nothing

#### Scenario: Receivers that are not provably SDK clients
- **GIVEN** `client.runs.stream(...)` on a parameter typed `Client`, `o.runs.stream(...)` with `o = new Other()` and `Other` imported as `Client` from another module, `late.threads.create()` with `let late = null; late = createLangGraphClient(token)`, `shared.threads.create()` where a parameter named `shared` shadows the module client, `other.threads.create()` on the return of an imported function that returns something else, and `x.runs.stream(...)` on the return of a function imported from a package
- **THEN** none of them consumes an endpoint or is counted
